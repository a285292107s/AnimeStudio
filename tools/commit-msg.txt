feat: 索引只存贴图、地图只支持 v2 紧凑格式

按「UI 图片提取」这个范围把索引和地图一起收窄。

索引只收贴图：
- Host 建索引固定带 --types Sprite Texture2D：资源浏览里已经没有类型筛选，
  音频/网格/脚本塞进地图只会让它大好几倍。绝区零 130,814 条 → 13 MB，
  首次 180 秒，增量重建 1 秒。
- 网页端删掉「类型」下拉，导出固定 Sprite + Texture2D；统计只剩资产总数 /
  Block 数 / 图库图片 / Sprite / Texture2D 五项。

只支持 v2 紧凑地图：
- 删掉 v1 逐条 MessagePack 的读取和写入（ForEachEntryMessagePack、MapFormat、
  --map_format 参数）。读到旧地图直接报「只支持 v2 紧凑地图（ASM2），请重新建索引」。
- 地图固定写在 <输出目录>\index\<索引名>.map，设置里的「地图路径」输入和
  「手动指定」标记一起删掉，HostSettings 里的 MapPath 也清掉。

增量缓存跟着过滤条件走：
- 缓存目录 <地图名>[.过滤指纹].mapcache：指纹包含类型/名称/容器过滤，以及
  加载到的 hash → 路径表（容器列会把路径烙进地图，换索引就该换缓存）。
- 缓存文件本来就存过滤后的条目，所以带过滤的建图不再退化成每次全量重扫。
- Host 统计「增量缓存」时把 <地图名>*.mapcache 全部加起来。

修正「只看有路径的」：
- 地图里绝区零的容器有两种：建图时用 Z3 索引换成真实路径的（71%），
  和索引也没收录、留着数字的（29%）。之前只判断 requireResolved 能不能在
  索引里解析，导致已经烙成路径的 92,697 条被全部过滤掉，页面显示 0 条。
- 现在 IsDisplayableContainer：能解析或是路径都算有路径，只有纯数字哈希被隐藏。
- 顺手修好「地图大小」显示 0.01 GB 的问题（统一走 fmtSize）。

测试与文档：
- 新增 map-v2-only 用例：旧 v1 地图既不算紧凑地图，也只报 ASM2 重建提示。
  现在 25 项检查全过。
- README 与 batch.html：参数 22 个 / 20 个 flag，删掉 --map_format，
  写清 v2-only、索引只收贴图、容器路径为什么是烙进去的。
