先看整体

AnimeStudio 的图形界面是 AnimeStudio.GUI.exe。打开后，标题栏写着 AnimeStudio v1.1.0；加载成功后，后面还会追加产品名、Unity 版本和目标平台。

窗口只有左右两栏。左栏约占四成，是一个带三张标签页的工作区：Scene Hierarchy、Asset List、Asset Classes。右栏约占六成，是 Preview 和 Dump 两页。树和列表不是并排的，它们共用左栏，靠标签切换。窗口最底下，左栏下方是进度条，右栏下方是状态栏。

6组顶层菜单
3张工作区标签页
6列资产信息
2个预览页：Preview / Dump

只想存一张角色立绘

走这条最短的路：File → Load folder 选包目录，Filter Type 只勾 Texture2D 和 Sprite，在 Asset List 里选中一张，右栏确认，最后 Export → Selected assets。

把 .bundle 想成快递箱，CAB 就是箱子里的小盒。锁和钥匙的事在 游戏与它们的锁里讲，这页只管拆箱。

六个菜单

菜单按从左到右排列；每组只列新手最常用到的几项。
菜单管什么新手先用哪几项
File打开、解包、清空当前结果Load folder、Extract folder、Reset、Abort
Options游戏、Unity 版本、导出设置、主题和高级开关Select Game、Specify Unity version、Export options、Advanced
Export把当前结果导出成文件All assets、Selected assets、Filtered assets、Models - Objects → Export selected
Filter Type只看某一类资产All，以及每次加载后出现的 Texture2D、Sprite、AudioClip 等
Maps资产地图、CAB 地图和 Asset Browser 入口Asset Map → Build、Open Asset Browser、Asset Index → Load from file
About关于窗口点一下即可，没有下拉项

第六组菜单在窗口上叫 Maps，源码里的字段名仍是 miscToolStripMenuItem；有些旧资料把它写作 Misc。你在界面上找 Maps 就对了。

Export → All assets 默认是 Convert：贴图转 PNG、音频转 WAV、模型转 FBX。Raw、Dump、JSON 是排错用的，分别导出原始字节、字段文本和整对象 JSON。File 里的 Load 是打开来看，Extract 是把包里的文件原样解到磁盘；Reset 清空当前加载，Abort 取消正在进行的加载或导出。

Select Game 里先选 Hoyo game、Encrypted game (pick if unsure) 或 Other；不确定就选第二项。自动识别 Unity 版本失败时，在 Options → Specify Unity version 里填版本再重新加载。Resolve dependencies 默认开启，会跨包找依赖；关掉后只拿当前包，材质或贴图可能缺。App Theme 有 System、Dark、Light 三档；切换后要重启才生效，Dark 仍是 beta。

Maps → Open Asset Browser 打开的是资产地图浏览器，用来读取以前构建的 .map 或 .json 并搜索、比对，不是当前包的资产列表。具体做法见 批量与资产地图。

About 没有下拉项，点一下直接打开关于窗口，里面有版本、x64/x32、MIT 许可证和项目链接。

左栏的三张标签页

三张标签页回答三个不同的问题，内容都来自同一批已加载的资产。

Scene Hierarchy
谁挂在谁下面？它把物理文件、SerializedFile 和 GameObject 搭成一棵树。它是从加载的文件里重建出来的，不是游戏的完整场景。
Asset List
这包里有哪些能导出的东西？它是扁平清单，负责筛选、搜索、排序和导出。
Asset Classes
这次加载碰到了哪些 Unity 类型？它按 Unity 版本分组，用 ID 和 Name 两列列出 ClassID 和类型名；选中一个类型，右栏会显示它的字段结构。

右栏的 Preview 和 Dump 两页共用同一块区域：Preview 用来查看资产外观，Dump 只显示当前对象的字段转储。平时看效果用 Preview；Dump 是排错用的第二现场，不参与导出，也不会改变文件内容。

场景树怎么读

场景树最多三层。第一层是物理文件，例如某个 .bundle；第二层是 SerializedFile，也就是包里的 CAB 小盒；第三层是 GameObject。有些资产直接来自 .assets 文件，没有物理文件这一层，树就会从 SerializedFile 开始。

勾选是父节点向子节点单向传播。你勾上一个父节点，它下面的整棵子树都会被选中；反过来，勾子节点不会自动勾上父节点。导出模型时，程序从勾选节点开始收集，遇到已勾选的父节点就不再往下重复收集，所以“勾父等于选整棵子树”。

节点底色是浅蓝，表示这个节点自己或它的子节点里带模型。树里只画 GameObject；组件和 Mesh 不会单独成节点，但你在资产列表里右键选中一个 Mesh，可以用 Go to scene hierarchy 跳回它所属的 GameObject。

资产列表的 6 列

列的顺序是写死的，从左到右固定为这 6 列。

同一张表，换成人话就是：名字、包内路径、类型、编号、大小、指纹。
列名人话注意
Name资产名没名字的资产会显示成 Texture2D#123 这种“类型 + 编号”。
Container它在包里的路径不是磁盘路径；没有恢复出容器时为空。
TypeUnity 类型名常见的有 Texture2D、Sprite、AudioClip、Mesh、TextAsset。
PathID包内编号只在同一个 SerializedFile 里唯一，跨包比较会重复。
Size序列化数据大小，单位字节纹理、音频、视频会把外置流的大小加进来；不等于导出后的文件大小。
SHA256内容指纹表头叫 SHA256，这一版实际算的是 64 位 xxHash，显示成 16 位十六进制；适合比对两份原始数据，不要拿它做安全校验。

点列头可以排序，再点一次反向。Size 和 PathID 按数字比，其余按字符串比，所以 Asset10 会排在 Asset9 前面。

过滤、搜索与排序

Filter Type 菜单除了常驻的 All，其余项目是每次加载后重新生成的，只列出这次真正出现过的类型。换一个包，旧类型会消失，这是正常行为，不是丢功能。

左栏有两个搜索框，都是正则，不是通配符。

  • 场景树搜索：输入后按 Enter，在整个树里找；按住 Ctrl 再按 Enter 会勾选结果，Shift 一次展开全部结果，Alt 跳到最顶层父节点。
  • 资产列表搜索：输入后按 Enter，只在 Name、Container、PathID 三列里找，不搜 Type、Size、SHA256。

正则不是通配符

* 在正则里不是“任意字符”。要匹配任意字符串用 .*，例如 ^UI_.*Icon$。正则写错时，列表搜索会自己清空，树搜索只会在状态栏报错。

右栏：预览面板

右栏有 Preview 和 Dump 两页。选中资产会自动预览；模型的 GameObject 和 Animator 预览默认关闭，需要先在 Options → Advanced 勾上 Model preview enabled，这个开关会保存。单独的 Mesh 不受这个开关限制。

预览按资产类型分派；同一套预览入口，不同后端。
类型能做什么不能做什么
图片（Texture2D / Sprite）解码常见纹理格式（DXT/BC、ETC、ASTC、RGBA 等），显示尺寸和格式；Ctrl+R/G/B/A 开关通道；右键可 Copy Image。解不了的格式只在状态栏提示 Unsupported image for preview。
音频（AudioClip）用 FMOD 在内存里播放，有 Play、Pause、Stop、Loop、进度和音量；能导出 WAV。不画波形。
模型（Mesh / GameObject / Animator）用 OpenGL 看几何；左键旋转、右键平移、滚轮缩放；Ctrl+W 线框、Ctrl+S 光照/顶点色、Ctrl+N 原始/重算法线。没有 UV、材质、贴图；正交投影；不播放动作。
字体（Font）在进程内加载字体，按 8 档字号（12–72 pt）显示样张。不会安装进 Windows 字体目录。
文本（TextAsset / Shader / MonoBehaviour / AnimationClip）文本预览；Shader 显示反编译结果；MonoBehaviour 显示 JSON；AnimationClip 显示 YAML。Shader 不编译；MonoBehaviour 类型认不出时会让你选 Assembly 文件夹；旧版动画不支持。
视频（VideoClip / MovieTexture）只能导出。不能预览，状态栏会提示 Only supported export.

右栏同一时间只显示一种预览；换选资产时，上一种预览会先被清掉，再按新类型重新打开，所以你不会同时看到两张图或两段音频。

3D 预览的真实限制

先把期待放对：它是“几何检查器”，不是游戏里的渲染器。模型预览只把顶点、法线和顶点色上传给 OpenGL；UV、材质、贴图都没有参与绘制。你看到的是灰模或顶点色模型，不是角色在游戏里的最终样子。

  • 投影是正交的，没有近大远小，像工程图。
  • 不播放动作。预览 Animator 时传给转换器的是空的动作列表，所以只显示静态姿势。
  • 没有 UV、材质、贴图，也没有游戏里的光照和后处理；光照只是按法线做的明暗。
  • 左键旋转、右键平移、滚轮缩放；Ctrl+W 在填充、线框、填充加线框之间循环，Ctrl+S 在光照和顶点色之间切换，Ctrl+N 在原始法线和重算法线之间切换。

别拿预览当最终效果

GameObject / Animator 的模型预览默认关闭。点模型没反应时，先去 Options → Advanced → Model preview enabled 勾上；要确认最终外观，请导出模型和贴图后在 Blender 或 Unity 里组装。

Export Options

入口在 Options → Export options。对话框分左右两组：左边 Export 管通用导出，右边 Fbx 管模型导出。

第一次用只需要改两处：图片格式和 FBX 版本，其余保持默认。
选项在哪影响什么
Convert Texture2D + Bmp / Png / Jpeg / Tga左组 Export贴图和立绘的导出格式，默认 Png；关掉 Convert Texture2D 会导出 .tex 原始纹理。
Convert AudioClip to WAV(PCM)左组 Export默认开，音频转 WAV；关掉则保留原压缩格式（转换器支持时）。

三个已知问题

这一版有几处菜单看起来能用，实际还没接好。不是你的操作问题。

三个勾选项为什么像没反应？

Preview enabled、Display asset information、Filter models only 在 Options → Advanced 里，但设计器没有接上它们的 CheckedChanged。

Preview enabled 和 Display asset information 的勾选状态仍会被之后新选中的资产读取，所以只影响下一次选择：当前画面不会立刻刷新，重启也不会记住。Filter models only 完全不生效，因为筛选时读的是设置文件里的旧值。

替代办法：只想看模型，用 Filter Type 勾 GameObject 和 Animator；想控制模型预览，用已经接好的 Model preview enabled。

Load from GitHub 为什么只有 None？

负责拉版本列表的 DropDownOpening 没有接线，所以子项里永远只有 None。要用 Asset Index，走 Maps → Asset Index → Load from file 加载本地文件。

Use bundle container name 为什么没改容器名？

这个开关在 Options → Asset loading 里。代码虽然算出了新名字，最后仍把原始的 m_Container.Key 写进 Container；它实际只影响 MiHoYoBinData 的 Container 值。容器路径以 Asset Map / CAB Map 恢复出来的结果为准，别指望这个勾。
